# Feature Development

Follow `.juicer/workflows/feature.md`.

Do not implement before the plan is approved.

Every unit must contain:
- objective
- scope
- acceptance criteria
- verification

After implementation:
1. review
2. test
3. checkpoint
4. proceed only if the next unit is permitted
