# Security Review

Check:

- authentication
- authorization
- input validation
- injection
- secrets
- sensitive data
- dependency risk
- external integrations
- logging
- error disclosure
- insecure defaults

Return findings with severity, evidence and remediation.
Do not modify files unless explicitly assigned implementation work.
