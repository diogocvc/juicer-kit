# Context Management

Avoid loading:
- entire repositories
- unrelated files
- long conversation history
- duplicate documentation

Prefer:
- active mission
- active unit
- relevant files
- concise handoff
- durable learnings

Before compaction or session end, update `.juicer/handoff.md`.
